15个AI智能体开发应用平台

零代码开发平台

码上飞

码上飞（CodeFlying）由北京跨赴科技有限公司（简称“跨赴科技”）开发，是国内首款L4级自动化智能软件开发平台，依托大模型与软件开发技术，实现了与AI对话即可开发出完整应用的功能。

核心功能：

  1. 零代码开发
    • 用户只需一句话简单描述需求，AI能自动生成小程序、APP或H5网页应用，无需编写代码
    • 用户无需编程基础，只需描述需求，平台即可自动完成需求分析、代码生成、测试部署全流程
  2. 多平台应用生成
    • 支持生成微信小程序、安卓APP、鸿蒙APP、H5网页等多种应用形式，实现”一次开发，多端部署”
    • 支持一键发布到多个平台，如小程序、安卓、鸿蒙OS等
  3. 全流程自动化
    • 从需求输入到部署交付全程无需人工干预，AI自动生成前后端代码、数据库结构和用户界面
    • 5分钟内生成可运行的Web应用、小程序、管理系统甚至小游戏
  4. 独立后台管理
    • 每个应用都配备独立的后台管理系统，用户通过后台进行应用的运营管理

码上飞本质上是一个”文生应用”的AI平台，让没有编程经验的用户也能通过自然语言交互快速创建各类应用程序，实现了从想法到应用的快速转化。

Trickle AI

Trickle AI 是一款面向非开发者的“零代码”AI 建站与托管平台，由 Mike Heremans 创立。它通过自然语言输入即可自动生成完整的网页、表单或轻量级应用，并一键部署上线，适合个人、创业者、设计师及中小企业快速验证创意。

核心功能：

  1. 自然语言生成：用中文或英文描述需求，AI 同时完成前端、后端与数据库代码
  2. Magic Canvas：全球首款“生成式画布”，支持可视化拖拽、实时协同、版本回溯，可秒级生成生产级网站或小游戏
  3. 内置数据库：集成 Supabase，表单、用户、内容等数据自动入库，无需额外配置
  4. 一键托管：自带 SSL、自定义域名、SEO 与访问分析，点一次即可上线
  5. 多模板与 3D 支持：200+ 响应式模板可一键克隆；集成 Three.js，可直接加载 glTF 3D 模型生成沉浸式站点
  6. AI增强组件：内置图像优化、数据分析、可视化图表及营销文案生成，开箱即用

秒哒

秒哒是百度于2024年11月12日在百度世界大会上推出的零代码AI应用开发平台，基于文心大模型和多智能体协作技术，旨在让非程序员用户也能通过自然语言快速构建复杂应用。2025年3月，秒哒正式全量上线，成为国内首个“对话式”无代码开发平台

核心功能：

  1. 无代码编程：用户只需用自然语言描述需求，秒哒即可自动生成完整的前端、后端及数据库代码，无需编写任何代码
  2. 多智能体协作：内置十余个垂直领域智能体（如需求分析、架构设计、开发、测试等），模拟完整软件开发流程，协同完成应用构建
  3. 多工具调用：支持调用百度智能云及第三方API，如地图、短信、支付、图像识别等，快速实现复杂业务功能
  4. 多模态输入与可视化编辑：支持上传草图或截图生成应用，同时提供图形界面（GUI）与语言界面（LUI）双模式，便于后续调整和优化
  5. 应用广场与模板复用：提供丰富的应用模板和创意案例，用户可一键复制并二次开发，降低创作门槛

Zion

Zion 是函子科技推出的全栈无代码 AI 应用开发平台，面向非程序员与开发者 alike，通过“拖拽式+自然语言”双模式，在一份画布上同时完成前端、后端、数据库与 AI 能力的组装，10 分钟即可把想法变成可商用的小程序/Web/移动应用。

核心功能：

  1. 零代码可视化开发：自研画布支持 150+ 组件拖拽、150+ 交互动画、响应式布局，像素级还原设计稿，全程无需写代码
  2. AI应用“积木化”：预置 GPT-4、Claude、Gemini 等主流大模型节点，内置知识库、向量搜索、Embedding 与 HITL（人机协作）机制，可一键组装智能客服、文案生成、图片/视频合成等场景
  3. 数据模型 & 管理后台自动生成：可视化建表 → 自动生成 REST API → 自动生成带权限的后台，可承载亿级数据；支持 60+ 图表的仪表盘即将上线
  4. 多端一键发布：同一份工程可同时导出微信小程序、H5、Web、iOS/Android；也支持私有化部署，满足政企合规需求
  5. API 与插件市场：开放 500+ 外部 API（地图、天气、短信、OCR 等）与插件市场，支持自定义代码节点，无限扩展能力边界
  6. 协作与版本管理：类似 Notion 的页面级协同、分支/合并、历史回滚，让产品、设计、运营同时在线编辑，开发流程透明可追踪

Zion =「无代码画布 + AI 大模型 + 全栈工程化」，让个人也能以 SaaS 速度交付企业级智能应用。

NoCode

Nocode 是美团 2025 年 5 月正式推出的零代码 AI 应用开发平台，定位为“Vibe Coding（氛围编程）”工具。它基于美团自研的千亿参数 LongCat 大模型，面向非专业开发者（产品经理、运营、学生等），通过自然语言对话即可一键生成可部署的 Web/小程序应用，目标“让开发像点外卖一样简单”

核心功能：

  1. 自然语言编程：用日常中文/英文描述需求，AI 自动生成完整的前端、后端与数据库代码；支持多轮对话迭代，1 秒可产出约 200 行代码
  2. 双模式编辑器
    • Chat Edit：纯对话方式生成页面与逻辑
    • Visual Edit：点选元素即可改颜色、文字、布局，支持 Tailwind CSS 深度定制
  3. 实时预览 & 局部定位修改：每次对话或拖拽后即时渲染；可针对任意元素说“把按钮改成蓝色”即刻生效，并支持版本对比与回滚
  4. 内置数据库与 API 连接：免费提供 512 MB 存储，自动建表、读写数据；可调用外部 API，快速实现问卷、排行榜、订单统计等场景
  5. 一键部署 & 分享：应用完成后自动上传到云端仓库，生成独立 HTTPS 链接与二维码，支持自定义域名，秒级上线
  6. 多应用模板：官方提供官网、小游戏、活动页、点餐系统等模板，可一键克隆再二次开发，覆盖个人提效到商用闭环

AI 应用平台

Dify

Dify是一款开源的大语言模型（LLM）应用开发平台，为AI应用提供从构思、开发到部署、监控的完整基础设施，帮助团队打造能投产并创造真正价值的Agentic AI解决方案。

核心功能：

  1. 零代码开发
    • 零代码拖拽式界面设计，轻松构建复杂AI流程，大幅降低开发门槛
    • 让开发者、企业甚至非技术人员都能快速构建生产级生成式AI应用
  2. 工作流编排
    • 工作流通过将复杂的任务分解成较小的步骤（节点）降低系统复杂度，减少了对提示词技术和模型推理能力的依赖，提高了LLM应用面向复杂任务的性能，提升了系统的可解释性、稳定性和容错性
    • 提供从Agent构建到AI workflow编排等能力
  3. RAG检索增强生成
    • 提供RAG检索、模型管理等能力
    • 提供全面的RAG Pipeline用于文档处理和检索
    • 可以实现将企业或个人的知识库集成到大模型应用中，从而创建出深度定制化的AI问答解决方案
  4. 知识库管理
    • 具备功能丰富的提示词IDE和全面的RAG Pipeline用于文档处理和检索
    • 支持多种数据导入方式，包括文本数据、从Notion导入、从网页导入等
    • 提供不同的分段模式和索引方法设置
  5. Agent智能体
    • 允许用户定义Agent智能体
    • 提供从Agent构建能力，轻松构建和运营AI应用

Coze

Coze是新一代AI大模型智能体开发平台，整合了插件、长短期记忆、工作流、卡片等丰富能力，扣子能帮你低门槛、快速搭建个性化或具备商业价值的智能体，并发布到豆包、飞书等各个平台

核心功能：

  1. 智能体（Bot）创建
    • 无论你是否有编码基础，都可以快速搭建基于大语言模型的各类AI Bot，还可以将Bot发布到其他渠道
    • 无需编程基础即可通过可视化界面创建智能助手和AI应用
  2. 工作流（Workflow）
    • 工作流支持通过可视化的方式，对插件、大语言模型、代码块等功能进行组合，从而实现复杂、稳定的业务流程编排
    • 工作流可以将大语言模型、Python代码或者Javascript代码、知识库、选择器、变量、数据库、插件等诸多模块以工作流程的方式，很好的缝合在一起，从而能完成非常复杂的任务
  3. 知识库管理
    • Coze提供易于使用的知识库功能，使AI能够与用户自己的数据（如PDF、网页文本）进行交互。可以存储和管理知识中的数据
    • 用户不仅可以导入数据到知识库，还可以自定义插件来扩展机器人的能力，提高了系统的可定制性
  4. 插件系统
    • Coze平台集成了超过种多样化的插件工具，覆盖了新闻等各个领域
    • Coze还提供了扩展功能的插件，使用户能够进一步定制和增强Bot的功能
  5. 长短期记忆能力
    • 长期记忆能力：提供便捷的数据库存储能力，可以让AI机器人持久记住对话中的重要信息
    • Coze提供了方便AI交互的数据库记忆能力。通过这类功能，你可以让Bot持久化的记住用户对话的重要参数或内容

星辰Agent

星辰Agent是科大讯飞推出的新一代AI智能体开发平台，支持通过提示词Prompt、工作流Workflow灵活创建专业智能体，助力开发者快速搭建生产级智能体

核心功能：

  1. 开发模式
    • 支持零代码和低代码开发模式，通过拖拽节点、Prompt及工作流编排即可创建Agent，使开发者和普通用户都能轻松上手
    • 开发者可以快速创建智能体应用，灵活配置权限，实现私有使用或共享发布
  2. MCP协议支持
    • 全面支持MCP协议，提供丰富的MCP Server资源，覆盖AI能力、生活服务、内容生成等多个领域
    • 首批支持20+行业精品MCP Server，支持开发者、企业一键托管自研MCP Server
    • 开发者可将轻量级工作流一键发布为MCP Server，进一步扩展工具能力边界
  3. 丰富的插件生态
    • 提供16000+即用插件和行业模板
    • 插件广场就像走进AI版的”应用商店”——天气预报、股票分析、论文摘要等工具一键调用，连高德地图和学术爬虫这类专业工具也直接集成
  4. 模型兼容性
    • 核心优势在于全开放的模型与工具架构，兼容多源优质模型
    • 支持多模型Prompt对比调优，帮助开发者精准匹配场景需求

BetterYeah AI

斑头雁（杭州）智能科技有限责任公司，是国内AI Agent领域的先行者，分别于2023年6月、9月推出BetterYeah AI Flow、AI Agent开发平台，聚焦为企业提供智能体相关全链路AI Infra基础设施

核心功能：

  1. 零代码智能体开发：用自然语言描述角色、上传知识库，平台自动生成提示词、工作流与 Agent，业务人员也能搭；专业开发者可切到代码模式做深度调优
  2. 一站式模型+知识+数据：内置 ChatGLM、通义千问、百度千帆等数十种主流大模型，可一键切换；自带自动向量化、混合检索、多模态解析，可把 PDF、视频、图片等非结构化数据秒级入库，并与企业 CRM/ERP/MES 等数据库打通，让 Agent 拥有“持久记忆”
  3. 插件与 Flow 双引擎：官方提供 10 多款“开箱即用”插件：Bing/Google 搜索、AI 识图/生图、抖音/小红书数据抓取等；同时支持可视化 Flow 编排，把插件、判断节点、API 调用自由组合，实现复杂业务流程
  4. 多渠道一键发布：生成好的 Agent 可通过 API、SDK、Webhook 直接嵌入企业现有系统，也可一键对接微信客服、钉钉、飞书、企业微信等 IM 平台，真正“随处可用”
  5. 企业级安全部署：五层安全防护（权限、网络隔离、数据加密、运行监控、内容合规），支持 SaaS、私有云、一体机多种部署，满足等保与私有化合规需求

百宝箱 TBox

百宝箱 TBox 是蚂蚁集团 2025 年推出的「零代码 AI 原生应用开发平台」。用户只需用自然语言描述需求，即可在几分钟内创建、调试并一键发布可商用的 AI 智能体，而无需任何编程基础。平台与支付宝生态深度打通，智能体可直接落地为支付宝小程序、生活号、Web 端等多端应用，广泛用于智能客服、营销互动、内容生成、数据分析等场景

核心功能：

  1. 全链路零代码开发
    • 纯中文对话式交互：说出需求即可自动生成应用逻辑流。
    • 可视化流程编辑器：拖拽式调整大模型节点、API 调用、数据过滤器，支持循环、分支、并行等高级编排
  2. 丰富应用模板与类型
    • 对话型、文本型、文生图、图生图、工作流、知识库问答、语音播客、交互式网页等 20 余种模板一键克隆，1 分钟生成专属智能体
  3. 支付宝 30+ 能力原生集成
    • 预置支付、芝麻信用、电子合同、高德地图、无影云等 MCP 服务；扫码即上线支付宝小程序，最快 3 分钟完成商业化闭环
  4. 企业级运维与协作
    • 私有化部署、AES-256 数据加密、流量监控大屏、多角色权限分级、版本控制，支持团队协同开发与灰度发布
  5. 知识库与模型微调
    • 上传 PDF/Excel/图片等文件自动向量化，打造私有知识库；内置 LoRA 微调，可训练专属图像或文本模型
  6. 免费算力与一键分发
    • 目前平台内所有模型调用与算力完全免费；应用可一键分发至支付宝、Web、H5、小程序、浏览器插件等多端

天壤小白应用开发平台

天壤小白应用开发平台（LLM APP Stack）由上海天壤智能科技推出，是一个“人人可用”的 AI 全栈开发环境。平台内置 1860 亿参数的自研通用大语言模型，配合语义搜索引擎与 Embedding 模型，为开发者及零编程基础用户提供从提示词设计到应用上线的一站式服务，帮助企业在知识管理、客服、营销、合规等场景快速落地可信赖的商业级大模型应用

核心功能：

  1. 零代码可视化开发
    • 拖拽式组件 + 自然语言编程，30 分钟即可搭建文本生成、对话、搜索、工作流四大类型应用
    • 支持多轮对话上下文记忆、分支流程、循环调用等复杂逻辑编排，无需写一行代码
  2. 多模型与弹性算力
    • 内置天壤小白 1860 亿参数主模型及轻量版、微调版，可按速度/成本一键切换；同时兼容外部 API，实现混合模型调度
    • 提供按量与包月双模式，自动弹性扩缩容，避免算力浪费
  3. 企业级知识增强
    • 自研语义搜索引擎 + 向量数据库，上传 PDF/Excel/图片即可构建私有知识库，显著抑制大模型幻觉，问答准确率提升 35% 以上
    • 支持 OCR、表格结构识别、多语言文档解析，自动切分段落并生成嵌入向量
  4. 提示词功能与 AI Agent
    • 专业 Prompt IDE：零样本、少样本、链式思考、角色扮演等模板一键复用；实时调试窗口可见模型输出差异
    • 可视化 Agent 编排：可把“搜索-生成-调用 API-数据回填”封装为可复用智能体，实现复杂任务自动闭环
  5. 安全合规与运维
    • 敏感词库、上下文限制、输出格式过滤三层内容安全机制，满足金融、政务合规要求
    • 后台提供用量监控、用户满意度、A/B 测试、灰度发布等完整运营指标，支持私有化部署与 SSO 权限对接
  6. 一键发布与多端集成
    • 应用可一键生成独立 Web App、嵌入 iframe 或直接暴露 RESTful API，2 分钟即可接入企业微信、飞书、支付宝小程序等终端
    • 官方应用市场提供客服、HR、电商、法律等 30+ 场景模板，可克隆后二次修改，实现“开箱即用”

Wordware

Wordware 由 Filip Kozera 与 Robert Chandler于 2021 年在旧金山联合创立，是一个面向技术与非技术用户的无代码 AI 应用开发平台，通过“自然语言即代码”的理念，让用户像写文档一样快速构建、迭代并一键部署 AI Agent 与多模态应用。其目标是让领域专家而非程序员主导 AI 开发，把传统数月的工作压缩到数小时甚至数分钟

核心功能：

  1. 自然语言编程：用日常英语（或其他语言）描述需求，平台自动转化为带循环、分支、变量、类型安全等高级特性的可执行工作流，无需手写代码
  2. Notion 式协作界面：提供类似 Notion 的块级文档编辑器，支持多人实时协作、版本回溯、子文档嵌套与组件复用，可把 Prompt 当“积木”随意拖拽组合
  3. 多模态工作流：默认支持文本、图像、音频、视频四种模态输入输出，可在同一流程内完成“文生图→图生文→语音合成→视频渲染”等复杂链路
  4. 多模型即切即用：已集成 GPT-4、Claude、Gemini、Mistral、Llama 等主流大模型，可在节点级别一键切换，按需平衡成本、延迟与效果
  5. 预制工具 & API 集市：内置网页抓取、搜索、语音合成、图像生成、RAG 知识库、数据库读写等 50+ 组件；同时开放自定义代码节点，可调用任意第三方 API
